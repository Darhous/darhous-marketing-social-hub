# بوابة درهوس للتسويق والسوشيال ميديا
# Darhous Marketing & Social Media Hub

A production-ready **Arabic-first Marketing & Social Media portal** for digital professionals and agencies in the Arabic-speaking market.

Built on the **Luminous Nexus** design system — Futuristic Glassmorphism, RTL-first, IBM Plex Sans Arabic.

---

## Status

🟡 **Stage 1 Complete — Orchestration Setup**  
🔵 **Next: Stage 2 — Foundation & Layout (Copilot)**

---

## Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript (strict)
- **Styling:** Tailwind CSS + Luminous Nexus design tokens
- **Font:** IBM Plex Sans Arabic
- **Direction:** RTL (Arabic-first)

## Project Structure

```
social/
├── docs/
│   ├── agent-briefs/          # Maestro plans and agent instructions
│   ├── agent-reports/         # Agent output and handoff logs
│   ├── copilot-tasks/         # Copilot implementation task files
│   └── checklists/            # QA and launch checklists
├── src/
│   ├── app/                   # Next.js App Router pages
│   ├── components/            # React components
│   ├── lib/                   # Utilities and mock data
│   └── types/                 # TypeScript types
├── stitch_darhous_marketing_hub/  # Design reference (READ-ONLY)
└── public/                    # Static assets
```
